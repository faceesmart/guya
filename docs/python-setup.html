One quick step: install Python

Guya needs Python to run. It's free, safe, and takes about two minutes. After this, just double-click Install Guya again.

1

Download Python

Click the button below. On the page, click the big yellow “Download Python” button.

⬇ Download Python (macOS)
2

Open the downloaded file

In your Downloads, double-click the python-…-macos.pkg file.

3

Click “Continue” → “Install”

Accept the defaults. Enter your Mac password if asked.

4

Done — re-open Guya

Double-click Install Guya again. ✅

1

Download Python

Click the button. On the page, click “Download Python” (the yellow button).

⬇ Download Python (Windows)
2

Run the installer

Open the downloaded python-…-amd64.exe.

3

IMPORTANT: check the box

At the bottom of the first screen, tick “Add Python to PATH”, then click Install Now.

4

Done — re-open Guya

Double-click Install Guya again. ✅

Tip: if you have someone helping you, this is a one-time step they can do for you. Guya itself works hands-on after this — just hold the key and speak.
